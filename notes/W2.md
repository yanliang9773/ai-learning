## 10-31 for...else：else 属于 for，不属于 if
**现象**：合并脚本时，成功 break 后却掉进"所有源失败"的兜底块
**原因**：break 只跳出循环，掉到循环下一行；原代码靠 return 分家，改 break 后没人分家了
**解决**：兜底块挂进 for 的 else,for循环 没被 break 过才执行
**泛化**：搬代码改了控制流（return→break），必须重新检查"每条路各通向哪里"；
        另外：给"平时走不到的分支"造现场（改坏 URL 模拟断网），测出来的 missing
        警告当场抓到样本缺 KRW——降级路径也是路径，值得有完整体验。

## 10-31 git push 三连卡：卡死 → 连不上 → 要认证
**链路**：QuickEdit冻结(假卡死) → schannel TLS错误(换openssl后端) →
        Could not connect(git不读系统代理，配 http.proxy 127.0.0.1:7897) →
        GCM弹认证窗(Token标签贴PAT) → 成功
**泛化**：①"浏览器能开、命令行连不上"= 代理差异，工具要单独配代理
        ②排障时"错误变了"就是进展，每次只改一个变量
        ③凭据会被 GCM 记住，一次认证永久生效

## 10-26 git status 里混进了 pip-unpack-*.whl
**现象**：git add . 后 status 出现几十个 whl 文件
**原因**：10-22 装包中断，pip 的临时解压目录留在项目里；git add . 是无差别收录
**解决**：删目录 + .gitignore 加 pip-unpack-*/ 和 *.whl + git reset 重新 add
**泛化**：commit 前必须看 git status —— add . 只保证"全都要"，
       status 才保证"要的都对"。垃圾进了 commit 历史就很难洗干净了。
